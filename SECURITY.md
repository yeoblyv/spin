# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately by email to **xineraman8@gmail.com**. Do not open a public issue for a suspected vulnerability.

Include a description of the issue, steps to reproduce, and the affected version (`spin --version` output).

## Response window

Expect an initial response within 5 business days.

## Supported versions

`spin` has not yet had a tagged release. Once releases begin, this section will list which versions currently receive security fixes.

## Disclosure

A reported issue is disclosed only after a fix has shipped, via the `CHANGELOG.md` entry for the patched release. The reporter is acknowledged unless they request otherwise.
